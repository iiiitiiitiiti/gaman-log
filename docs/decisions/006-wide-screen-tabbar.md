# 006: 広い画面では、タブの並びだけを中身と同じ幅に収める

- 日付: 2026-09-29
- 状態: 採用

## 決めたこと

タブバーの背景と上の線は画面いっぱいのまま、ボタンの並ぶ範囲を左右の余白 `(100% - 520px) / 2` で中身（`.content` の最大 520px）と同じ幅に収める。552px 未満の画面では従来どおり左右 16px。

## 理由

中身はすでに最大 520px で中央に寄っていたが、タブだけが画面の端から端へ散らばり、1024px 以上では押す場所が中身から離れていた。

## 却下した案

| 案 | 却下理由 |
|---|---|
| `.app` に `max-width: 480px; margin: 0 auto`（デザインレビューの提案） | 背景の水玉・色面まで細い帯になり、左右が無地で途切れる。中身はすでに 520px で揃っており、足りないのはタブだけだった |
| タブバーごと 520px の浮いた箱にする | 下端に固定した帯という今の形が崩れ、スマホとの見た目の一貫性が落ちる |

## 検証

375・551・700・1024・1440px で、タブの左右端が中身の左右端と揃うこと（スクロールバーが常に出る環境では、その幅の半分ほど右へずれる）と、375px の配置が変更前と同じことを確認。横スクロールは出ない。
