# 005: 回る後光は、回らない切り抜き枠で画面幅に収める

- 日付: 2026-09-29
- 状態: 採用

## 決めたこと

回転する後光（`.sunburst`、780px 四方）を、回らない枠 `.sunburst-clip` で包み、枠に `overflow: clip` を付けて左右を画面幅で切る。枠は `.content` の左右 16px の余白ぶんだけ外へ広げ、見た目は変えない。

## 理由

375〜1024px の画面で、はみ出した後光が横スクロールの余地になっていた（scrollWidth が clientWidth を超える）。スクロール枠 `.scroller` は縦スクロールなので、そこへ `overflow-x: clip` を足しても仕様上 `hidden` 扱いになり、プログラムからは横へ動かせてしまう。回る要素そのものではなく、回らない親で切れば、回転中も切り口が動かない。

## 却下した案

| 案 | 却下理由 |
|---|---|
| `.scroller` に `overflow-x: clip` | 縦が `auto` だと `hidden` に計算され、scrollLeft で横へ動く余地が残る |
| `.hero` に `overflow: hidden`（デザインレビューの提案） | 上下も切れるため、見えている光の筋が途中で途切れる |
| 後光を画面幅より小さくする | 光が画面の端まで届く見た目が変わる |

## 検証

375・390・1024px で scrollWidth と clientWidth が一致し、scrollLeft を強制しても 0 のままなのを確認。修正前後のスクリーンショットで見た目が変わらないことを確認した。横スクロールがまた出たら、この枠の外へはみ出す要素が増えたことを疑う。
