# 002: 「がまん」と「むだづかい」を別の世界観にする

- 日付: 2026-09-24
- 状態: 採用

## 決めたこと

1つの部品構成のまま、`.app--saved` / `.app--wasted` のデザイントークン（色・線・影・角丸・書体）を切り替えて、2つのタブをまったく違うテイストにする。

- がまん: 貯金箱の世界。レモン色の地にドット、太い縁と「ずらし影」のステッカー調、回る後光、極太書体（Dela Gothic One）の巨大な金額、記録するとコインが降る
- むだづかい: 警報の世界。深い紫の地に走査線、警告テープ、ドット文字（DotGothic16）の電光掲示板、記録すると画面が赤く点滅して揺れる
- タブ切り替えは次の世界の色の幕が横切る演出でつなぐ

## 理由

- ユーザーの要望が「ポップ」「タブごとにテイストが異なる」「UI は全力で振り切る」
- 部品を分けずにトークンだけで切り替えると、機能追加が片方に偏らない

## 却下した案

| 案 | 却下理由 |
|---|---|
| 同じデザインで色だけ変える | 「テイストが異なるページ」の要望に届かない |
| タブごとに別コンポーネントを作る | 機能の二重実装になり、片方だけ直し忘れる |

## 配慮

- 当初は端末で「視差効果を減らす」（prefers-reduced-motion）が有効ならアニメーションを止めていたが、2026-09-24 にユーザーの指示で撤回し、設定に関わらず演出を出す。ユーザーの iPhone ではこの設定が有効で、記録後の演出が一切出ず「機能していない」状態になっていた。演出はこのアプリの主役なので、止めずに出すほうを採った
- 設定は3つめのタブ（地は水色）にし、がまん・むだづかいの定番ボタンを1画面に並べる（2026-09-24 変更。当初は右上の歯車から開くパネルで、開いていたタブの種類の分しか編集できなかった）
- タブを画面下に固定しきるため、ページ全体ではなく中身の領域（`.scroller`）だけをスクロールさせる。iOS はページ全体を引っ張ると `position: fixed` の要素ごと動くため
- 金額は桁数に応じて文字サイズを縮め、7桁でも 320px 幅に収める
