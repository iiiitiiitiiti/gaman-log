# 004: 目標・上限・振り返りタブを足す

- 日付: 2026-09-24
- 状態: 採用

## 決めたこと

- **がまんの目標**は「目標を決めた日からのがまん額」でゲージをためる。達成したら設定で外して、次の目標を立て直す（0から）
- **むだづかいの月の上限**を決められる。超えたら警報板を赤く点滅させ、超えた瞬間の記録ではポップでも知らせる
- **振り返り**は4つめのタブにする（がまん／むだづかい／ふりかえり／設定）。月の合計・直近6か月の棒グラフ・品目ランキング・自慢用画像を置く
- **連続記録**は、アプリを開いたときの画面内の表示だけにする（今日まだ記録していなければ「今日がまんで○日連続！」）
- 目標・上限・最終書き出し日・自分用の換算表は、`AppData` の省略可能な項目として足し、`version: 1` のまま読み書きする

## 却下した案

| 案 | 却下理由 |
|---|---|
| 目標を「これまでのがまん額の合計」でためる | 目標を立てた瞬間に進んでいて、ためる手応えがない（ユーザーが「決めた日から」を選択） |
| 目標を「がまん − むだづかい」でためる | 煽りにはなるが、がまん画面の「ためる楽しさ」と逆向きになる |
| 振り返りを各タブの下に置く | がまんとむだづかいを並べて比べられない（ユーザーが4つめのタブを選択） |
| 連続記録が途切れそうな日に通知を送る | iPhone でアプリを閉じているあいだに通知するにはサーバー（Web Push）が要る。端末内だけで完結させる方針（001）と合わない |
| データの version を 2 に上げる | 足した項目はすべて省略可能で、古い書き出しファイルもそのまま読める。移行処理を書く必要がない |

## 注意点

- 自慢画像のプレビューは `blob:` URL の `<img>` なので、CSP の `img-src` に `blob:` を足した
- 画像を作る処理は非同期なので、共有シートはプレビューを見てからもう一度押してもらう（共有シートは操作の直後にしか開けない）
