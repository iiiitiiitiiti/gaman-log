# 003: 金額の換算は2〜10個買える品目から入れ替えて選ぶ

- 日付: 2026-09-24
- 状態: 採用

## 決めたこと

「○○ぶん浮いた！」の品目は、その金額で2〜10個買えるものを候補にし、金額から決まる番号で1つ選ぶ。同じ金額のあいだは同じ品目で、金額が変わると入れ替わる。候補が無いとき（60円未満の少額や、600万円を超える高額）は、1個以上買える中でいちばん高いものにする。

## 理由

換算表を27段に細かくしたところ、「買える中でいちばん高いもの」では1つの品目が出る金額の幅が狭くなった（牛丼は500〜549円のときだけ）。ユーザーが牛丼などを出したいと望み、選択肢から「候補から毎回ちがう品目」を選んだ。

## 却下した案

| 案 | 却下理由 |
|---|---|
| 買える中でいちばん高いもの（初期実装） | 品目を増やすほど各品目の出番が減り、いつも1個ぶんになる |
| 3個以上買える中でいちばん高いもの | 絵文字は並ぶが、牛丼が出るのは1,500〜1,649円だけで狭いまま |
| 品目を減らして粗くする | ユーザーが細かくしたいと望んだ方向と逆 |
| 表示のたびに乱数で選ぶ | 画面を描き直すたびに品目が変わり落ち着かない。金額から決めれば同じ金額では安定する |
