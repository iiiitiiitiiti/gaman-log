# 001: 端末内保存（localStorage）の PWA にする

- 日付: 2026-09-24
- 状態: 採用

## 決めたこと

Vite + React + TypeScript の PWA を GitHub Pages で公開し、記録は端末の localStorage に1つの JSON（キー `gaman-log:v1`）で保存する。ログインや同期は持たない。

## 理由

- 1人で使う記録アプリで、データ量は多くても数千件（数百 KB）。localStorage で足りる
- 既存の自作アプリ（flashcards）と同じ技術構成にし、Mac と Windows のどちらでも同じ手順で開発できるようにした
- ユーザーが「端末内だけ」を選んだ

## 却下した案

| 案 | 却下理由 |
|---|---|
| Firebase などで複数端末同期 | ログインの仕組みと運用が増える。ユーザーが不要と判断 |
| IndexedDB | データが小さく、非同期 API の複雑さに見合わない |

## 注意点と対策

- iPhone では Safari のタブとホーム画面アプリの保存場所が別。Safari のタブのままだと7日間使わないとデータが消える → Safari で開いたときに「ホーム画面に追加」の案内を出す
- ホーム画面アプリではダウンロードリンクが不安定 → 書き出しは共有シート（`navigator.share` にファイルを渡す）を優先し、使えない環境ではダウンロード、別途クリップボードへのコピーも用意
- 読み込みは id で統合（同じ id は読み込んだ側で上書き）。実行前に件数を見せて確認する
