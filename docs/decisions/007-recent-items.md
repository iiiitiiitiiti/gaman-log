# 007: 定番ボタンの下に「最近の記録」を置き、1タップで同じ金額を記録する

- 日付: 2026-10-15
- 状態: 採用

## 決めたこと

がまん・むだづかいの記録画面で、定番ボタンの下に「最近の記録」を小さなボタンで並べる。押すと、同じ品名・絵文字・金額ですぐ記録する。

- 新しい順に最大6件。品名・絵文字・金額がそろって同じ記録は1つにまとめる
- 値段つきの定番ボタンと同じもの（名前が空の定番は「名前なし」として比べる）は、すでにボタンがあるので出さない。値段なしの定番（衝動買いなど）から金額を入れた記録は出す
- 未来の日時の記録は入れない（ほかの集計と同じ扱い）
- 金額が違ったときは、記録後のポップの「取り消す」か、履歴から直す
- 画面下の「履歴」はそのまま（タップで直す・✕で消す）

## 理由

「そのほか」や値段なしの定番で入れたものは、同じものをまた入れるたびに品名と金額を打ち直していた。ユーザーが次の2つを選んだ。

| 案 | 採らなかった理由 |
|---|---|
| 今の「履歴」の各行に「もう一度」ボタンを足す | 履歴まで下へスクロールしないと押せない |
| 押したら金額欄を開いて確かめてから記録する | 1手間ふえる。違ったときは取り消せば足りる |

## やらないこと

- 最近の記録を固定する・消す操作（記録が増えれば押し出される）
- 定番ボタンへの昇格（設定の定番ボタン編集で足りる）
